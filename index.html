Tracking — Help

Overview

The Tracking page shows the latest reported position of each entrant on the event route.

Use the map to view all entrants, identify delayed or stale tracking reports, follow a selected entrant, review entrants near controls, and centre the map on the full event, a control, or an entrant.

Event, day and route details are available in Settings.

Main buttons

Entrants

Opens the Entrants card.

  • All Entrants shows the full route and all available entrants.
  • Controls opens Controls View.
  • Selecting an entrant centres the map on that entrant and opens the entrant card.

Settings

Opens the display settings.

  • Entrant dot size.
  • Marker label: None, Number, or Number + Name.
  • Default selected-entrant trail.
  • Controls View zoom level.

Tracking — desktop only

Opens the Tracking setup card, which provides the Tracking event upload, access to the Google tracking log, the mobile Tracking PWA links, and the separate Tracking Google Apps Script connection.

Tracking is an additional, separately managed facility. It draws entrant, rally and mapped-route information from the Rally application, but Tracking setup and uploads are independent of the Admin and Controls uploads.

Entrant dots and colours

Each dot represents the entrant’s latest reported position.

Green — Active
The entrant is moving and recent tracking information is available.
Orange — Delayed
The latest tracking report is later than expected.
Flashing orange — Stale
No sufficiently recent tracking report has been received. The displayed position is the entrant’s last known position.
Grey — Past or Finished
The entrant has passed the selected control or completed the route.
Red — Selected entrant
The entrant card is open and that entrant is being followed. The red dot remains visible as new positions are received.

A coloured ring around a selected red dot can still indicate its underlying delayed, stale, past, or finished status.

Marker labels

Settings offers three marker-label choices:

  • None — dot only.
  • Number — rally number beside the dot.
  • Number + Name — rally number and entrant name.

The default is Number. Select either the dot or its label to select the entrant.

Entrant card

Selecting an entrant opens a fixed card showing:

  • rally number and entrant name;
  • current tracking status;
  • latest speed;
  • reported GPS accuracy.

The card remains open while the entrant continues moving. Select × to close the card and return the dot to its normal status colour.

Entrant trail

The buttons at the bottom of the entrant card control the displayed breadcrumb trail:

  • None — no trail.
  • 5 min — recent five-minute trail.
  • 10 min — recent ten-minute trail.
  • All — all available positions for that entrant.

The trail is shown as small breadcrumb dots behind the entrant.

Centre control

Select ◎ to restore the appropriate map view.

  • All Entrants — centres the full route and entrants.
  • Controls View — centres the selected control at the Settings zoom level.
  • Selected entrant — centres the selected entrant.

Controls View

Open Entrants, then select Controls.

Choose a control to review entrants relative to that point. Entrants are classified as:

  • before the control;
  • past the control;
  • delayed;
  • stale;
  • finished.

Grey dots indicate entrants that have already passed the selected control. Use the Centre control to return to the selected control after moving or zooming the map.

Tracking event upload

Select Upload tracking data to send a Tracking-specific copy of the current Rally project, entrants and route to the separate Tracking Google connection.

After a successful upload, the Copy, Email and WhatsApp buttons share a compact mobile link that identifies the uploaded Tracking event.

Tracking information

Tracking positions are received from the entrant’s mobile Tracking PWA.

The displayed location is the latest accepted report. A poor mobile signal or interrupted GPS report can delay the next update, so a stale marker is a last known position rather than confirmation that the entrant has stopped.
